# 🏓 ESP32 + FC-51 乒乓球自動計分與裁判系統

這是一個基於 ESP32 與 FC-51 紅外線避障感測器的乒乓球自動計分系統。

## 🌟 專案特色
- **自動進球偵測**：乒乓球通過 FC-51 感測器時自動加 1 分（僅限感測器觸發，防止人工手動加分）。
- **即時網頁看板**：ESP32 內建 Web Server，手機或電腦連上同一 Wi-Fi 即可看到大螢幕比分。
- **裁判違規扣分**：網頁介面提供「違規扣 1 分」按鈕（最低扣至 0 分，不出現負數）。
- **比分歸零**：提供一鍵 Reset 重置比分功能。

## 🛠️ 硬體準備
- ESP32 開發板 x 1
- FC-51 紅外線感測模組 x 2
- 杜邦線與麵包板

### 接線方式
| 元件 | FC-51 腳位 | ESP32 GPIO |
| :--- | :--- | :--- |
| 紅隊感測器 | VCC / GND / OUT | 3.3V / GND / **GPIO 18** |
| 藍隊感測器 | VCC / GND / OUT | 3.3V / GND / **GPIO 19** |

## 🚀 使用說明
1. 使用 Arduino IDE 開啟 `esp32_scoreboard.ino`。
2. 修改程式碼中的 `ssid` 與 `password` 為你的 Wi-Fi 資訊。
3. 燒錄至 ESP32 並開啟序列埠監視器（115200 baud）。
4. 連接序列埠監視器中顯示的 IP 位址即可開啟網頁看板。
